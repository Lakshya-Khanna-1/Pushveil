## [0.1.0] - 2026-08-29

### Added

- Global, cross-platform Git hook installer with existing-hook chaining and safe uninstall.
- Streaming scans across every commit introduced by a push.
- Detection in intermediate, deleted, renamed, large, and binary blobs.
- Git LFS object resolution and scanning.
- Exact `PUSH ANYWAY` interactive confirmation with fail-closed non-interactive behavior.
- Manual scans, JSON output, configuration, custom rules, allowlists, and diagnostics.
- Cross-platform CI, release automation, security policy, and isolated end-to-end push tests.
